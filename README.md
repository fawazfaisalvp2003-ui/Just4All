# ⚖️ Just4All – Justice for Everyone

### Justice for Everyone. Rights Within Reach.

**Just4All** is an AI-powered legal information assistant designed to make Indian legal knowledge easier to understand and accessible to everyone.

It helps users understand legal problems, explore their rights, discover possible legal actions and generate basic legal document drafts through a simple, multilingual interface.

Our mission is to make legal awareness more accessible, regardless of language or background.

## 🌟 About the Project

Understanding legal procedures, rights and available remedies can be difficult for ordinary people. Complex legal terminology and limited access to legal information often make it challenging to know where to start.

**Just4All addresses this challenge using Artificial Intelligence.**

By integrating Google's Gemini AI with a user-friendly Streamlit application, Just4All provides simplified legal information and practical guidance in English and Malayalam.

## ⚙️ Installation and Setup

Follow these steps to run Just4All on your local machine.

### Prerequisites

- Python 3.10 or later
- Git
- Google Gemini API key
- Visual Studio Code (recommended)

### Step 1: Clone the Repository

```bash
git clone https://github.com/fawazfaisalvp2003-ui/Just4All.git
```

### Step 2: Navigate to the Project Folder

```bash
cd Just4All
```

### Step 3: Install Dependencies

```bash
pip install -r requirements.txt
```

### Step 4: Configure Your Gemini API Key

Create a folder named `.streamlit` in your project directory.

Inside it, create a file named `secrets.toml`.

Add your Gemini API key:

```toml
GEMINI_API_KEY = "YOUR_GEMINI_API_KEY"
```

Replace `YOUR_GEMINI_API_KEY` with your actual API key.

**Important:** Never share or commit your API key.

### Step 5: Run the Application

```bash
python -m streamlit run app.py
```

The application will open in your browser.
